Privacy policy

Last updated: 22 November 2026

ORDELVA Automation is used only by the owner of the ORDELVA YouTube channel to publish and manage that channel's own videos.

Data accessed

  • YouTube channel information (channel ID, title, upload playlist) – to confirm the correct channel before uploading.
  • The channel's own videos, captions and statistics, and YouTube Analytics reports (views, watch time, average view percentage, subscribers gained) – to verify uploads and to write weekly performance reports.

How data is used and stored

  • Data is used only to upload, verify and analyse ORDELVA's own videos. It is never sold, shared with third parties, or used for advertising.
  • The OAuth refresh token is stored as an encrypted GitHub Actions secret. Access tokens are short-lived and never stored.
  • Aggregated video statistics are kept in the project's state files.

Google API Services

ORDELVA Automation's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Through the ORDELVA YouTube channel (youtube.com/@ordelva) or the project's issue tracker.
